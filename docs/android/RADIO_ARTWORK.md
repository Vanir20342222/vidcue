# Radio artwork

Provider-owned image, artwork, cover, thumbnail, logo or favicon URLs take precedence.
When a station has no valid HTTP(S) artwork URL, a genre photograph is used.
The photographs illustrate listening genres. They do not show the station or a
currently playing artist.

## How a photograph is chosen

- Each genre scene lists whole-word cues from the station's name, genre and description.
  Scenes are checked in order, so specific genres win over general ones.
- Stations in one scene take that scene's photographs in turn while the page
  lasts. The 15-station cliamp catalog therefore gets 15 different pictures.
  Radio Browser pages may repeat a photograph once a scene runs out.
- The shared image cache chooses from the advertised 120, 250, 500 and 960 pixel
  variants. Commons serves these standard steps; other widths return HTTP 400.
- Photographs keep their aspect ratio. They are not cropped to a square, so a
  non-square image shows inside its box.
- Failed artwork requests never block radio playback.

## Licences and credits

Each photograph is a Wikimedia Commons file. The table lists its licence.

- CC0 and public-domain photographs need no attribution.
- CC BY and CC BY-SA photographs require credit to the author, and CC BY-SA
  requires that adapted versions keep the same licence. vidcue does not modify or
  redistribute these images beyond resizing for display. The file page linked in
  each row has the full licence text.

Photographs were selected from Commons search and category listings on
2026-11-02. The file page for each row is the authoritative source for its
licence and author.
